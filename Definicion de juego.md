Regiones: Las Regiones de Brilliant se dividen en 5

Es importante que se hagan las siguientes funciones:

una para saber si una región ya esta llena

Otra para insertar un numero en esa región

Una función para cambiar el estado de lleno



Cada región tiene:

  * Puntuaje
  * Limite fijo de celdas
  * Un booleano que nos indica si esta lleno
  * Dependiendo del color tienen un tipo:

    * Color: Amarillo, Azul, Verde, Rojo y Morado
    * cada tipo tiene sus reglas
    * Reglas:

      * Amarillo y rojo: Los números no se pueden repetir dentro de esa región
      * Morado: Las celdas deben llenarse con el mismo numero
      * Azul: Las celdas deben llenarse con 2 números distintos
      * Verde: Las celdas pueden llenarse con cualquier numero







Las celdas son objetos dentro del juego las cuales tienen:

Coordenada

Valor de 1-6
